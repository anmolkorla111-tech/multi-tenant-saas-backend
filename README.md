# Multi-Tenant SaaS Backend

This project is built using FastAPI and PostgreSQL.

## Features

- Create User API
- Duplicate Email Validation
- Mark Attendance
- Get Attendance List
- PostgreSQL Database
- Swagger Testing
- Postman Testing

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Uvicorn

## How to Run

1. Activate virtual environment
2. Install requirements
3. Run:
   python -m uvicorn main:app --reload

Swagger:
http://127.0.0.1:8000/docs
